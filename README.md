# OpenBridge AI — Prototype v0.1

OpenBridge is an independent, nonprofit-minded project exploring how to make digital opportunity easier to reach.

## What's included
- Responsive landing page
- Mission and principles sections
- Searchable starter directory of AI, creation, coding, and learning resources
- Category filters
- Official provider links
- No login, API key, backend, or paid service required for this prototype

## Run it on Windows
1. Download and extract `openbridge-ai.zip`.
2. Open the extracted `openbridge-ai` folder.
3. Double-click `index.html` to preview it in your browser.

For editing, install Visual Studio Code and open the folder using **File → Open Folder**.

## Important prototype notes
- This is a front-end prototype, not yet a complete nonprofit service.
- Tool pricing, eligibility, privacy terms, and availability can change. Verify each provider's current terms before publishing claims.
- Next milestones: source-reviewed directory, accessibility review, contribution process, privacy policy, governance model, and deployment.

## Suggested project structure
- `index.html` — page structure
- `style.css` — responsive visual design
- `app.js` — directory data, search, and filters
